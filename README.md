# Zelunexa — Site Oficial

Site institucional e comercial da **Zelunexa**, com apresentação das soluções **Zelunexa Monitor** e **Zelunexa Guia**.

**Slogan:** Conectar para zelar.

## Estrutura

- `index.html` — página principal
- `monitor.html` — Zelunexa Monitor
- `guia.html` — Zelunexa Guia
- `sobre.html` — empresa e fundadores
- `contato.html` — contato comercial
- `area-do-cliente.html` — Área do Cliente
- `privacidade.html` — Aviso de Privacidade
- `termos.html` — Termos de Uso
- `assets/` — estilos, scripts, imagens e vídeos
- `vercel.json` — configuração de publicação na Vercel

## Execução local

O site é estático. Para visualização simples, abra `index.html` em um navegador moderno.

Para executar com servidor local:

```bash
python -m http.server 8080
```

Depois, acesse `http://localhost:8080`.

## Publicação

O projeto está preparado para hospedagem estática e publicação pela Vercel.
